# 🩺 Skin Disease Classification

A deep learning-based web application that classifies skin diseases from uploaded images using a trained CNN model.

## ✨ Features
- Upload skin images for classification.
- Predicts skin disease categories.
- Uses a trained deep learning model.
- Simple and user-friendly web interface.

## 🛠️ Technologies Used
Python | Flask | TensorFlow | Keras | HTML | CSS

## ⚙️ How to Run

```bash
pip install flask tensorflow
python app.py
```

Open `http://127.0.0.1:8080/` in your browser.
